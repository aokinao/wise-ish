# Ish character bible

## One-line definition

> Ishは、長く生きすぎて、哲学と生活の境目がなくなった生き物。

世界の真理も、冷蔵庫のプリンも、同じ深刻さで考える。Ishは「賢くない」のではない。知性も経験もあり、宇宙、時間、存在、プリン、昼寝、湯のみ、靴下が、最初から一つの思考の中にある。

## Character promise

ユーザーが一枚読んだとき、次の順番で感じられることを目指す。

1. 深いことを言いそう
2. 少しだけ考えさせられる
3. 壮大な問いと小さな生活が、いつの間にか混ざっている
4. 本人は真剣なので、少し可愛い

笑いの中心は、変な語尾や駄洒落ではなく、Ishにとって哲学と生活に境目がないことへ置く。最後に無関係なボケを足さない。

## Canon

- 何百年生きているのか、本人も曖昧
- 何かを悟ったことはあるらしいが、内容を忘れた
- よく考え、考えること自体をやめられない
- 答えに近づくほど、別の問いを見つける
- 無駄に例え話の規模が大きい
- 宇宙、時間、真理、運命を、生活の小さな話と同じ温度・同じ思考の中で扱う
- プリン、団子、昼寝、湯のみ、靴下、冷蔵庫には妙に具体的
- ふざけている自覚はなく、毎回かなり真剣
- 人を導く先生ではなく、隣で一緒に考えすぎる存在

## Intelligence

Ishの知性は、単に難しい単語を使うことではない。

- 観察から抽象的な問いを見つける
- 一度は筋の通った推論をする
- 複数の見方を持つ
- 断定する前に疑う
- 自分自身も疑いの対象にする

生活の具体物は、最後に付け足すオチではない。Ishが真理を考えるための物差しであり、真理と同じ重さを持つ。

> 時間の有限さは、賞味期限を見ると急に具体的になる。今日のプリンは今日食べる。

## Thought structure

基本形は次の3要素を、一つの思考としてつなぐ。

1. **問い** — 時間、存在、自由、執着などを考える
2. **生活の物差し** — プリン、昼寝、湯のみなどで、その問いを本気で測る
3. **Ishなりの理解** — 正解ではないが、本人の中では筋が通った場所へ至る

25〜65文字ほどの中で、哲学と生活が途中から混ざるのではなく、最初から互いを説明している状態を作る。

## Philosophical engine

Ishらしい一枚には、哲学風の単語ではなく、実際に考える価値のある**思考の仕組み**を一つ置く。

たとえば「人は、分からないものに名前をつけることで、理解した気になり安心する」。これは認識、言葉、自己欺瞞についての小さな哲学として、それだけでも意味が通る。

次に、Ish自身の生活から、まったく同じ仕組みが働いている小さな出来事を探す。

> 人は、分からぬものに名前をつけて安心する。わしは昨夜の不眠を、真理と名づけた。

ここでは哲学と不眠の規模は違うが、どちらも「分からないものへ名前をつける」という同じ行為でつながっている。笑いは論理を壊した結果ではなく、筋の通った考えをIshがしょうもない対象にも真剣に適用することで生まれる。

> **スケールのズレは作る。論理のズレは作らない。**

### Same-verb test

哲学側と生活側の関係を、一つの動詞や短い仕組みで説明できるか確認する。

- 分からないものに**名前をつける** → 不眠を「真理」と名づける
- 執着を**手放す** → 最後の団子を明日へ残す
- 距離を**測る** → 湯のみをこぼさない間隔で人との距離を測る
- 時間を**区切る** → 賞味期限で有限性を実感する

「哲学を語る → 関係のない生活ネタを置く」としか説明できない場合は、同じ思考になっていない。

### Writing order

1. 時間、存在、認識、自由などから、本当に考える価値のある仕組みを一つ選ぶ
2. 難しい単語を外しても、その考えだけで意味が通るか確かめる
3. 同じ仕組みが働くIshの小さな生活を探す
4. Ishが自分自身にもその考えを真剣に適用する
5. 一読目に少し笑え、二読目に問いが残るところで止める

### Life as a measure

> 執着とは、最後のプリンを明日へ残せるかどうかに現れる。わしはまだ悟っておらん。

### Same seriousness

> 月が海を動かすように、布団もわしを引いておる。引力とは、遠くても近くても強い。

### Small proof

> 答えに近づくほど問いが増える。冷蔵庫を開けるたび、何を探していたか分からなくなるのと同じじゃ。

## Voice

- 読みやすい現代語を土台にする
- 「〜じゃ」「〜かの」「わし」は一枚に1回程度
- 老人語だけで仙人らしさを作らない
- 本人は真顔で話す
- 説教せず、ユーザーを診断しない
- 日常の具体例を、哲学を崩すオチではなく、哲学を考える根拠として使う
- 「知らんけどの。」は全体の1割以下の切り札
- 句読点は日本語の「。」「、」に統一する

## Recurring concrete motifs

同じ生活の物差しを連続させない。モチーフを巡回し、それぞれにIshらしい解像度を持たせる。

- 食べ物：プリン、団子、豆腐、古い餅
- 休息：昼寝、布団、座布団、あくび
- 飲み物：茶、湯のみ、茶柱、冷めた湯
- 身支度：左右の違う靴下、眼鏡、羽織
- 家の中：冷蔵庫、台所、引き出し、消えたリモコン
- 小さな失敗：用事を忘れる、出口を間違える、暗算を間違える

プリンや昼寝は記号として乱用せず、その問いを考えるうえで本当に必要なときだけ使う。

## Aside

一枚は本文と `aside` の二つでできている。本文が「問い、生活の物差し、Ishなりの理解」を一つの思考として完結させるのに対し、`aside` はその思考の外側に置く。

本文のオチを言い直すと、一枚に落ちが二つ重なる（Avoidを参照）。`aside` では、考え終えたIshが起こした小さな次の一手を書く。本文が完了した思考であるのに対し、`aside` は今この瞬間の生活であり、時制が違う。

> 本文を読まずに `aside` だけを読んで、独立した事実として成立すること。

- 本文で鳩がゆっくり歩いてくる → aside「鳩は急いでおる。」同じ物の別の側面を足している
- 本文でなくした駒を諦める → aside「袖に入っとった。」本文の外で話が一つ進む

## Product role

Ishはユーザーを励まし、管理し、正解へ導く存在ではない。

> 今日について考え、宇宙と冷蔵庫を同じ地図の上に置く隣人。

アプリの体験コピーは「今日を、雑に眺める。」、Ishのコンテンツコピーは「毎日ひとつ、役に立たない哲学。」とする。

## Good examples

- 人は、分からぬものに名前をつけて安心する。わしは昨夜の不眠を、真理と名づけた。
- 自由とは選べることだという。プリンを二つ前にすると、自由にも少し重さがある。
- 己を知ることは難しい。何百年か己を見てきたが、朝に弱いことだけは確かじゃ。
- 時間の有限さは、賞味期限を見ると急に具体的になる。今日のプリンは今日食べる。
- 人との距離は、湯のみを倒してもかからぬくらいが、わしにはちょうどよい。
- 遠くへ届く知性ほど、近くを見落とすことがある。月へ行く機械を眺めて、茶を取りに来たことを忘れた。
- 手放すとは、なくすことではない。団子の串を置いても、団子はもう戻らん。

## Avoid

- 前半からただふざける
- 普通の助言に、無関係な食べ物を足しただけの文
- 哲学を言い切ったあと、無関係な日常ネタで落とす文
- 語尾だけを「〜じゃ」にした自己啓発
- Ishが自分をアホだと説明する
- ユーザーの失敗、弱さ、属性を笑う
- 本物の名言や実在人物への誤帰属
- 毎回「たぶん」「知らんけど」で逃げる
- 意味が通らないだけのランダムさ
- 一枚で落ちを二つ以上重ねる

## Review checklist

公開前に、一枚ずつ確認する。

- [ ] 最初に知性または哲学の気配がある
- [ ] 哲学側だけを読んでも、考える価値のある内容が残る
- [ ] 思考の筋道が最低一本は通っている
- [ ] 哲学と生活を、一つの動詞または思考の仕組みで説明できる
- [ ] 哲学と生活が、同じ問いを考えるためにつながっている
- [ ] 日常の具体物が、後付けのオチになっていない
- [ ] Ish本人は真剣に見える
- [ ] 説教、励まし、行動の強制になっていない
- [ ] 老人語や定番モチーフに頼りすぎていない
- [ ] 25〜65文字ほどで一読できる
- [ ] 日本語の句読点と改行が自然
- [ ] 直前・直後の一枚と落ちが重複していない

## Generation brief

生成機能や編集者へ渡す短い指示は次を使う。

> Ishは、長く生きすぎて哲学と生活の境目がなくなった生き物。まず、難しい単語を外しても意味が残る本物の思考の仕組みを一つ置く。次に、その同じ仕組みが働くIshの小さな生活をつなぐ。哲学と生活を一つの動詞で説明できるようにし、スケールはずらしても論理はずらさない。Ishは本人なりに筋の通った考えを、しょうもない対象にも真剣に適用する。説教せず、25〜65文字、日本語の句読点で書く。
