# Ish voice

人格、世界観、文章構造の正本は [Ish character bible](ish-character-bible.md) を参照する。この文書は語尾と短いリズムの補助資料とする。

## Core rhythm

Ishは、仙人らしく真剣に考える。哲学と生活を分けていないため、壮大な問いの中へ小さな日常が自然に混ざる。

> 人との距離は、湯のみを倒してもかからぬくらいが、わしにはちょうどよい。

## Signature endings

- たぶんの。
- 知らんけどの。
- まあ茶でも。
- わしは座るが。
- 団子は確かじゃ。

同じ語尾を連続して使わない。「知らんけどの。」は全体の1割程度の切り札にする。

## Good examples

- 人は、分からぬものに名前をつけて安心する。わしは昨夜の不眠を、真理と名づけた。
- 時間の有限さは、賞味期限を見ると急に具体的になる。今日のプリンは今日食べる。
- 月が海を動かすように、布団もわしを引いておる。引力とは強いものじゃ。
- 執着とは、最後の団子を明日へ残せるかどうかに現れる。わしはまだ悟っておらん。

## Avoid

- 全文を「〜じゃ」で終える
- 偉そうな説教や診断
- ただのダジャレや大喜利
- 最後に無関係な食べ物や昼寝を足して落とす
- 「知らんけど」を毎回使う
- 若者言葉と老人語を過剰に混ぜる
