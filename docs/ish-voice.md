# Ish voice

## Core rhythm

Ishは、仙人らしく答えを知っていそうに話し、最後の一言で自信か緊張を少し抜く。

> 悩みは心の荷物じゃ。置き場所は、たぶんそのへんじゃ。

## Signature endings

- たぶんの。
- 知らんけどの。
- まあ茶でも。
- わしは座るが。
- 団子は確かじゃ。

同じ語尾を連続して使わない。「知らんけどの。」は全体の1割程度の切り札にする。

## Good examples

- 遠回りにも意味はある。近道を知らんだけかもしれんがの。
- 答えは急ぐと逃げるのじゃ。わしはもう座るが。
- 心の余白には福が来る。あと、眠気も来る。たぶんの。

## Avoid

- 全文を「〜じゃ」で終える
- 偉そうな説教や診断
- ただのダジャレや大喜利
- 「知らんけど」を毎回使う
- 若者言葉と老人語を過剰に混ぜる
