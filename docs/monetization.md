# マネタイズ方針

個人開発の趣味アプリとして、作り込みすぎない範囲で決めた方針です。

## 決めたこと

**買い切り一本。サブスクは入れない。**

月額は「毎日使わないと損」を生むため、「毎日使わせるのではなく、毎日そこにある」という原則と正面から戦うことになる。一日一枚しか出さないので、単価も見えすぎる。

## 無料と有料の境目

境目は**言葉ではなく、棚**に置く。

| | 無料 | 買い切り |
| --- | --- | --- |
| 今日の一枚 | 見られる | 同じ |
| ウィジェット | 使える | 同じ |
| お気に入り | 残せる | 同じ |
| 言葉の棚 | 自分が受け取った分だけ | これまでの全枚を読める |
| 履歴 | 直近のみ | 全期間 |

**今日の一枚は課金で変わらない。**全ユーザーが同じ日に同じ言葉を見る状態を保つ。これは共有したときに会話が成立する条件でもある。

ウィジェットも課金対象にしない。ウィジェット単体で体験が成立することは中核の原則なので触らない。

## 買ったあとに追加された言葉

**含む。**あとから買った人のほうが有利になるのはおかしい。

この形なら構造的にそうなる。追加された枚は棚に並ぶだけで、購入時点で何かが確定する仕組みがない。そのため「以後の追加を含む」と表記で約束する必要もない。

## 実装

- プロダクトID `com.naoki.Wiseish.wordshelf`（非消耗型・買い切り）
- App Store Connectへの登録手順は [in-app-purchase-setup.md](in-app-purchase-setup.md) にまとめた
- `Wiseish/Wiseish/WiseishStore.swift` がStoreKit 2で購入と権利判定を持つ
- 「言葉の棚」画面に「棚」タブを追加した。未購入は案内、購入済みは全枚を表示する
- 「日々」タブは未購入で直近7日まで、購入で全期間
- 購入の復元は棚の案内と設定の両方から行える
- シミュレータ検証用に `Wiseish/Wiseish.storekit` を置き、Wiseishスキームへ紐付けた

`quotes.json` の `isPremium` フィールドは削除した。課金の境目が個々の言葉ではなく棚の解放に移ったため、不要になった。

## 決めていないこと

- 価格（¥400〜600のあたりを想定）
- 棚のどこで購入を案内するか。主体験の邪魔にならない置き方にする
- 広告は入れない。3秒で閉じる画面に置くと面積の大半を占めるため
