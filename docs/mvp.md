# MVP scope

## Completion goal

アプリを開くと、大きな日付、今日の数字、一言、Ishが一画面で目に入り、同じ内容をホーム画面のウィジェットでも確認できること。

## Included

- 大きな日付と曜日
- 今年の何日目、残り日数、経過率のいずれか一つ
- 今日の一言
- 今日を一緒に眺めるIshと短い独り言
- Small / Mediumウィジェット
- 日付・時間帯・端末内の文脈による選択
- 選択や入力を要求しない初回オンボーディング
- 控えめな通知許可とWidget案内
- ダークモード
- お気に入り
- 直近7日間の履歴
- ローカルJSONの迷言データ
- オンデバイスLLMが利用可能な場合の選択補助
- AI非対応・準備中・失敗時のフォールバック
- 「今日のWise-ish」を返すApp Intent

## Deferred

- ユーザー投稿
- ソーシャル機能
- Android版
- 天気連携
- カレンダー連携
- HealthKit連携
- 位置情報
- クラウド同期
- サーバー側LLM
- Todo、習慣、ストリーク、ランキング
- 今日の問いへの回答や達成チェック

## Delivery order

1. ローカルJSONから今日の言葉を決める
2. メイン画面を作る
3. App Groupに今日の結果を保存する
4. WidgetKitで同じ結果を表示する
5. お気に入りと履歴を追加する
6. Ishへの返事と端末内の文脈選択を追加する
7. オンデバイスLLMを追加する
8. App Intentsを追加する

## Non-functional requirements

- オフラインで基本体験が成立する
- 同じ日はアプリとウィジェットで同じ言葉を表示する
- AIの有無でUIが壊れない
- 個人の文脈を文章のまま外部へ送らない
- 迷言が読み切れる文字量を優先する
