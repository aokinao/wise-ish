# MVP scope

## Completion goal

アプリを開くと今日の日付と迷言が表示され、同じ内容をホーム画面のウィジェットでも確認できること。

## Included

- 日付と今日の迷言
- Ishの静止ポーズと短いリアクション
- Small / Mediumウィジェット
- 気分の手動選択
- お気に入り
- 直近7日間の履歴
- ローカルJSONの迷言データ
- オンデバイスLLMが利用可能な場合の短い言い換え
- AI非対応・準備中・失敗時のフォールバック
- 「今日のWise-ish」を返すApp Intent

## Deferred

- ユーザー投稿
- ソーシャル機能
- Android版
- 天気連携
- カレンダー連携
- HealthKit連携
- 位置情報
- クラウド同期
- サーバー側LLM

## Delivery order

1. ローカルJSONから今日の言葉を決める
2. メイン画面を作る
3. App Groupに今日の結果を保存する
4. WidgetKitで同じ結果を表示する
5. お気に入りと履歴を追加する
6. 気分選択を追加する
7. オンデバイスLLMを追加する
8. App Intentsを追加する

## Non-functional requirements

- オフラインで基本体験が成立する
- 同じ日はアプリとウィジェットで同じ言葉を表示する
- AIの有無でUIが壊れない
- 個人の文脈を文章のまま外部へ送らない
- 迷言が読み切れる文字量を優先する
