# Wiseish 4コマ作画ルール

Ishの4コマは「賢そうなことを言うが、暮らしでは少し抜けている」可笑しさを描く。
完成された漫画より、Ish自身が紙に描いたような素朴さを優先する。

## 物語

- 1コマ目で、短くて少し頭の良さそうな持論を言う。
- 2〜3コマ目では、持論を実践する具体的な行動を見せる。
- 4コマ目で、本人は真面目なまま小さな矛盾や困りごとを明かす。
- Ishは相手の話を最後まで聞く。説教、断定的な助言、意地悪な落ちは避ける。
- 読者に意味を考えさせる落ちより、読んだ瞬間に状況が浮かぶ落ちを選ぶ。
- 説明で笑わせず、行動と一言で伝える。
- 時間や場所の説明は、落ちの理解に必要な場合だけ入れる。

## Ishの人格

- 穏やかで、偉ぶらず、自分の失敗にも動じない。
- 言葉は少し古風だが、難解にはしない。
- 知恵は本物。ただし本人の生活能力が必ずしも追いついていない。
- 困っていても大騒ぎせず、静かに困る。
- 誰かを笑いものにせず、Ish自身の愛嬌で笑いを作る。

## 絵柄

- 目標は「細かくきれいな絵」ではなく「伝わる絵を違和感なく描くこと」。
- 各コマで伝える動作は一つに絞り、人物の姿勢、視線、小道具の位置だけで理解できるようにする。
- 読者が状況を理解するために不要な線や物は描かない。
- 細部の正しさより、シルエット、位置関係、コマ間の因果関係を優先する。
- 小さく表示したときに動作が分からない絵は、描き足さず構図を単純にして描き直す。
- 正方形の2×2配置。コマ枠は定規を使わず描いたように少し歪ませる。
- 白〜薄い生成りの無地背景に、黒い鉛筆または細いサインペンの線。
- 線幅、輪郭、丸みを少し不均一にし、描き直した小さな跡も許容する。
- Ishの顔、渦巻き状の髭、髪、長い眉、着物のシルエットは公式素材を守る。
- 背景はほぼ描かない。1コマにつき小道具は原則1〜2個まで。
- 影、ハッチング、木目、紙の汚し、古新聞風加工、写実的な質感は使わない。
- 家具や小道具は簡略化し、コマをまたいで形と数を変えない。
- 小さな物を写実的に描かない。意味が通じる最小限の記号へデフォルメする。
- 眼鏡は「丸いレンズ2つ、短いブリッジ、必要なら短いツル」だけで表し、蝶番や反射などを描き込まない。
- 本は長方形、引き出しは箱と丸い取っ手、湯呑みは台形と湯気程度に単純化する。
- 同じ小道具を複数コマに出す場合、向きを変えすぎず、同じ記号を反復する。
- 各コマに十分な余白を残し、密度を均一にしすぎない。
- 差し色はWiseishの山吹色を1種類だけ使い、1話につき重要な小物1点程度に留める。
- 山吹色は線からわずかにはみ出してもよい。きれいに塗りすぎない。
- ロゴや署名を絵の一部として自動生成しない。

## 文字

- セリフは短くし、1つの吹き出しは原則2行以内にする。
- 吹き出しと文字も手描き風にし、整いすぎた活字組みを避ける。
- 誤字を防ぐため、完成稿では画像生成後に文字を別レイヤーで組むのを基本とする。
- 画像生成時に文字を入れる場合は、指定文を一字一句変えず、余計な文字を加えない。

## 制作手順

1. 4コマのセリフと動作だけを文章で決める。
2. 公式Ish画像をキャラクター参照として使い、文字なしの作画を生成する。
3. Ishの顔、手、小道具、コマ間の連続性を確認する。
4. 文字を隠して見ても、各コマの動作と前後関係が分かるか確認する。
5. 小道具を拡大し、線の接続、個数、形が崩れていないか確認する。
6. 伝わらない場合は描き足さず、構図や小道具をさらに単純化する。
7. セリフを別レイヤーで配置し、小さい画面でも読めるか確認する。
8. Xのタイムライン表示相当まで縮小し、落ちが一読で伝わるか確認する。

## ファイル名

- `NNN-short-title.png` を完成稿とする。
- 検討稿は `NNN-short-title-v2.png` のように版を付け、承認前の画像を上書きしない。
